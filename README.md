# Bhakthula Sai Chandu — Portfolio

A single-file, animated personal portfolio (HTML, CSS and JavaScript, no build step).

## Run locally
Open `index.html` in any browser.

## Publish on GitHub Pages
1. Create a new repository, for example `portfolio`.
2. Upload `index.html` and `README.md`.
3. Go to Settings → Pages, choose the `main` branch and the `/ (root)` folder, then save.
4. Your site will be live at `https://<your-username>.github.io/portfolio/`.

## Notes
- The resume PDF is embedded in the page, so the Download Resume buttons work without extra files.
- The contact form opens the visitor's email app (mailto). For direct sending, connect a service such as EmailJS.
